## ✨ 核心特性

### 🎨 批量生图
一次性输入多个提示词，全自动逐条生成，无需人工值守。

### 📥 自动下载
生成后自动下载，支持自定义保存目录。

### ✨ AI 提示词增强 [v2.0+]
内置 AI 优化功能，一键将简单描述转化为专业级英文提示词。
- 支持多模型：DeepSeek R1、GLM-4.1V 等
- API 服务商预设：SiliconFlow / DeepSeek / OpenAI
- 完全自定义：自带 API Key 即可使用

### 🖼️ 智能图生图
- **[v2.0+] 点选上传**：每条提示词下方有独立上传模块
- **[v1.2.0+] 智能匹配**：文件名 `1_xxx.jpg` 自动匹配第一条提示词
- **自动压缩**：大于 1MB 的图片自动压缩至 1024px

### ⚡ 一键去水印 [v2.0+]
内置去水印实验室功能，快速去除 Gemini 生成图片的水印。

### 📚 提示词库 [v2.0+]
- 保存常用提示词，随时一键调用
- 支持关键词搜索
- 批量管理和清空

### 📊 实时进度
直观的进度条显示，实时掌握生成动态。

### 💾 状态持久化 [v2.0+]
提示词和参考图上传后关闭插件窗口，再次打开时数据不会丢失。

## 🚀 使用教程

### 第一步：打开 Gemini 页面

访问 [https://gemini.google.com/app](https://gemini.google.com/app) 并确保已登录

> **注**：v1.1.1 版本已完整支持繁体中文界面（港澳台）。

### 第二步：准备提示词

在插件输入框中输入提示词，支持多种格式：

**方式一：一行一条**
```
一只可爱的猫咪坐在窗边
一只金毛犬在公园玩耍
一朵盛开的玫瑰花
```

**方式二：三减号分隔**
```
一只可爱的猫咪坐在窗边
---
一只金毛犬在公园玩耍
---
一朵盛开的玫瑰花
```

**🌟 方式三：AI 提示词增强 [强烈推荐]**

> [!TIP]
> **一键批量生成多角度、多环境提示词！** 只需输入简单描述，AI 自动帮你生成专业级英文提示词。

**示例：生成 5 张不同角度人像**

输入：
```
一个女孩，五张，5种不同角度和环境
```

AI 自动生成五条不同版本的提示词，并自动用---进行分隔，支持叠加参考图进一步优化生成体验。
```

**操作步骤：**
1. 点击右上角 ⚙️ 配置 API Key（推荐 SiliconFlow 免费额度）
2. 输入中文描述 + 数量要求（如"五张"）
3. 点击 ✨ 按钮，等待 AI 生成

### 第三步：添加参考图（可选）

**方式一：点选上传 [推荐]**
- 输入提示词后，下方自动显示每条对应的上传模块
- 点击 `+` 按钮直接添加参考图

**方式二：批量导入 + 智能匹配**
- 图片命名为 `1_xxx.jpg`、`2_xxx.jpg` 格式
- 点击 🖼️ 导入，自动匹配到对应提示词

### 第四步：开始生成

1. 点击"🎨 批量生成"按钮
2. 等待自动生成和下载
3. 图片保存到默认下载目录（或您指定的目录）

### 第五步：一键去水印（可选）

1. 批量生成完成后，会自动弹出提示
2. 点击"⚡去水印"按钮
3. 选择需要处理的图片（支持多选）
4. 处理后的图片自动下载，添加 `_wr` 后缀

## 🔧 常见问题 (FAQ)

### 基础功能
- **Q: 工具主要做什么？**
  一次性输入多行提示词，全自动逐个生成图片并下载到本地，无需人工值守。

- **Q: 如何使用 AI 提示词增强？**
  1. 点击右上角 ⚙️ 配置 API Key（推荐 SiliconFlow）
  2. 输入中文描述，点击 ✨ 按钮
  3. AI 自动生成专业英文提示词

- **Q: 参考图怎么匹配到提示词？**
  - **v2.0 全新方式 [推荐]**：输入提示词后，下方自动显示每条对应的**点选上传模块**，直接点击 `+` 添加参考图，无需改名，更加便捷！
  - **原有方式 [完全兼容]**：图片命名 `1_xxx.jpg` → 自动匹配第一条提示词，批量导入时仍可使用

### 故障排除
- **Q: 插件无法找到输入框？**
  1. 确保在 `https://gemini.google.com/app`
  2. **刷新页面**（通常是输入框未加载完成）

- **Q: 下载下来是 .html 文件？**
  请在地址栏点击"锁"图标 → 网站设置 → **允许自动下载**

- **Q: API 提示词增强报错？**
  检查 API 端点是否包含 `/v1` 后缀（如 `https://api.siliconflow.cn/v1`）

## 📁 项目结构

```
Nano-Banana-Flow/
├── manifest.json      # 扩展配置文件
├── popup.html         # 弹窗界面
├── popup.css          # 界面样式
├── popup.js           # 弹窗逻辑
├── content.js         # 内容脚本（核心）
├── background.js      # 后台服务
├── icons/             # 图标资源
├── images/            # 主题图片
└── lib/               # 功能库（去水印等）
```

## 🛠️ 技术栈

- **Manifest V3**：Chrome 最新扩展标准
- **Content Script**：DOM 操作和页面交互
- **Service Worker**：后台任务管理
